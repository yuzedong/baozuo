敬拜投影软件使用帮助

快速上手 经文与清单 诗歌与歌谱 多屏与 PPT 常见问题

快速上手

  1. 选择投影屏幕

    打开敬拜投影软件，在右上角点「投屏设置」，确认目标屏幕已连接。若要指定屏幕，关闭「自动选择一块屏幕」，勾选目标屏幕，再点「保存选择」。

  2. 预览并投出第一段经文

    在搜索框输入「约 3:16–18」，点「查找」并核对右侧「投影预览」，然后点「投影到大屏」。客户端会在选定的屏幕上打开投影窗口。

  3. 准备下一段

    继续查找并预览下一段。此时大屏仍在播放上一段，待你再次点击「投影到大屏」后才会切换。

经文与清单

  1. 查找经文

    可按书卷和章浏览，也可搜索经文位置或正文关键词。例如「约三章十六至十八节」。跨章可输入「约 3:35–4:2」。

  2. 选择范围

    点击一节可单选。按住 Shift 再点击另一节，可选择两节之间的连续范围。需要全章时点「选整章」。

  3. 合并多段经文一起投影

    一次读经需要用到多段经文时，可以先把选段排成一份清单，再一次投到大屏。选段可以来自不同章节或书卷，大屏会按清单顺序显示，每段都有自己的经文出处。内容超过一屏时，可在操作台滚动继续展示。

    1. 逐段加入。例如先查找并选中「约 3:16–18」，点「加入清单」。再查找并选中「约 3:19–21」，也点一次「加入清单」。每段都会加到清单末尾。
    2. 调整顺序。在右侧「合并投影清单」里，用每段旁的上移或下移箭头调整读经顺序。选错一段时点该段旁的「移除」。
    3. 核对整份清单。右侧若正在预览单段经文，点「预览清单」。如果按钮已显示「返回选段」，表示当前已在预览整份清单。
    4. 投影到大屏。确认右侧预览里的经文和顺序后，点「投影到大屏」。加入、调整和预览都在待播区完成，大屏会在点击投影后切换到这份清单。

  4. 核对上屏内容

    点「查看上屏」核对大屏画面，点「返回待播」继续准备。经文超出一屏时，可用滚轮或上下方向键滚动，上屏画面的滚动位置会同步到大屏。

用 Ctrl + K（Mac 为 ⌘ + K）聚焦搜索框，用 Alt + Enter 上屏。

诗歌与歌谱

  1. 查找诗歌

    在操作台顶部切换到「诗歌」，按首号、歌名或已导入的文本歌词搜索。想缩小范围时，选好诗集并勾选「仅当前诗集」。

  2. 选择资料并投影

    选中曲目后，按该首可用的资料选择歌词、简谱或五线谱。确认右侧预览，再点「投影到大屏」。

  3. 放大或缩小歌谱

    打开简谱或五线谱，等右侧谱面加载完成后，点击预览下方的「＋」放大或「−」缩小。两颗按钮之间的百分比表示谱面宽度，可根据大屏的大小和观看距离调整。

    上屏前可以先在预览区调好大小，再点「投影到大屏」。当前预览的谱面已在大屏显示时，调整会立即同步到大屏。

  4. 导入诗歌资料

    先选诗集并点「下载模板」。填写 JSON 后，点「导入诗歌资料」，同时选中 JSON 和它引用的图片。支持 PNG、JPEG 和 WebP。

  5. 替换歌谱

    打开曲目的简谱或五线谱，点「替换歌谱」。可替换单页或整首、调整页序，也可以恢复原谱。导入和替换的资料保存在当前应用的本机数据中。

多屏投影与切换 PPT

  1. 选择多块屏幕

    在「投屏设置」关闭「自动选择一块屏幕」，勾选投影仪或返看屏，再点「保存选择」。可同时选多块屏幕显示同一份内容。

  2. 切换到 PPT 并恢复投影

    要暂时让出大屏给 PPT，点「最小化投影」或在投影窗口按 Esc。PPT 结束后，回到操作台点「恢复投影」。

常见问题

投影仪没有出现在「投屏设置」里
检查投影仪电源、输入源和连接线。在电脑的显示设置中确认外接屏幕已识别并设为扩展显示，再回到「投屏设置」选择目标屏幕。
投影窗口打开了，大屏还是黑色
首次上屏前是黑屏。请先选一段经文或一首诗歌，确认预览有内容，再点「投影到大屏」。若画面出现在电脑屏上，请检查扩展显示和目标屏幕的选择。
歌谱打不开或需要离线使用
安装版首次读取尚未缓存的在线谱图需要联网。恢复网络后可点「重试歌谱」。有离线需要时，可在聚会前逐首打开要用的谱图并确认预览可读。
重新接好投影仪后画面没有恢复
先到「投屏设置」确认目标屏幕已连接。若显示「未连接」，重新勾选当前屏幕并保存，再点「投影到大屏」。
