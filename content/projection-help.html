敬拜投影用于在聚会中查找经文和诗歌，在操作台预览后投到大屏。第一次使用时，按下面的步骤连接屏幕并试投一段经文。

快速上手 经文与清单 诗歌与歌谱 多屏与 PPT 常见问题

快速上手

  1. 连接投影仪或电视，在电脑的显示设置中选择扩展显示器。
  2. 打开敬拜投影。桌面版用右上角的「投屏设置」选择目标屏幕。网页版点「打开投影」，将弹出的窗口拖到大屏，再点投影页上的全屏提示。
  3. 在搜索框输入「约 3:16–18」，核对右侧「投影预览」，然后点「投影到大屏」。
  4. 需要准备下一段时，可以继续查找和预览。再次点「投影到大屏」后，大屏才会切换到新内容。

经文与清单

  • 查找经文。可按书卷和章浏览，也可搜索经文位置或正文关键词。例如「约三章十六至十八节」，跨章可输入「约 3:35–4:2」。
  • 选择范围。点击一节可单选。按住 Shift 再点击另一节，可选择两节之间的连续范围。需要全章时点「选整章」。
  • 合并多段。每选好一段就点「加入清单」。在「合并投影清单」里调整顺序，点「预览清单」，核对后再投影到大屏。
  • 核对上屏内容。点「查看上屏」可核对大屏正在显示什么，点「返回待播」可继续准备。经文超出一屏时，可用滚轮或上下方向键滚动，上屏内容的滚动位置会同步到大屏。

用 Ctrl + K（Mac 为 ⌘ + K）聚焦搜索框，用 Alt + Enter 上屏。

诗歌与歌谱

  1. 在操作台顶部切换到「诗歌」，按首号、歌名或已导入的文本歌词搜索。想缩小范围时，选好诗集并勾选「仅当前诗集」。
  2. 选中曲目后，按该首可用的资料选择歌词、简谱或五线谱，确认预览后点「投影到大屏」。
  3. 要导入自己的资料，先选诗集并点「下载模板」。填写 JSON 后，点「导入诗歌资料」，同时选中 JSON 和它引用的图片。支持 PNG、JPEG 和 WebP。

只需换谱页时，打开该曲目的简谱或五线谱，点「替换歌谱」。可替换单页或整首、调整页序，也可以恢复原谱。导入和替换的资料保存在当前应用的本机数据中。

多屏投影与切换 PPT

桌面版。在「投屏设置」关闭「自动选择一块屏幕」，勾选投影仪或返看屏，再点「保存选择」。可同时选多块屏幕，显示同一份内容。要暂时让出大屏给 PPT，点「最小化投影」或在投影窗口按 Esc。需要继续投影时，点「恢复投影」。

网页版。可用「收起投影」和「恢复投影」切换。若恢复后浏览器提示「点击进入全屏」，请到大屏上的投影窗口点击该提示。

常见问题

点击「打开投影」后没有弹窗
允许浏览器弹出窗口，或点击提示中的「在新标签页打开投影」。使用网页版时，建议用 Chrome 或 Edge 打开操作台和投影页。
投影窗口打开了，大屏还是黑色
首次上屏前是黑屏。请先选一段经文或一首诗歌，确认预览有内容，再点「投影到大屏」。若画面出现在电脑屏上，请检查扩展显示和目标屏幕的选择。
歌谱打不开或需要离线使用
安装版首次读取尚未缓存的在线谱图需要联网。恢复网络后可点「重试歌谱」。有离线需要时，可在聚会前逐首打开要用的谱图并确认预览可读。
重新接好投影仪后画面没有恢复
桌面版可先检查「投屏设置」里的连接状态，然后点「投影到大屏」。网页版则检查投影窗口是否在大屏上，以及是否已全屏。
