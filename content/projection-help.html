聚会时，大屏还在放幻灯片，讲道人可能下一秒就提到一句经文。操作员可以在同一个操作台快速查经、找歌谱，也能放映幻灯片、播放视频和音频。查找和预览时，会众看到的仍是原来的画面。核对内容后，只需一键投到指定的投影仪或大屏。

快速上手

  1. 选择投影屏幕

    打开敬拜投影软件，在右上角点「投屏设置」。软件会自动列出电脑识别到的投影仪和大屏，默认优先选择一块外接屏幕。要自己指定时，关闭「自动选择一块屏幕」，勾选要投到的一块或多块屏幕，再点「保存选择」。

  2. 预览并投出第一段经文

    在搜索框输入「约 3:16–18」，点「查找」并核对右侧「投影预览」，然后点「投影到大屏」。客户端会在选定的屏幕上打开投影窗口。

  3. 准备下一段

    继续查找并预览下一段。此时大屏仍在播放上一段，待你再次点击「投影到大屏」后才会切换。

经文与清单

  1. 点书卷、章号和节号，快速定位

    比如讲道人提到约翰福音 3 章 16 节，在「新约」点「约」，章节选择会自动打开。点「3」后，软件会自动打开节号面板。再点「16」，右侧立即显示第 16 节。核对后点「投影到大屏」。

  2. 查找经文

    知道经文位置，可以输入「约 3:16–18」，跨章可输入「约 3:35–4:2」。只记得一句经文时，输入正文关键词，点「查找」，再从结果中选中对应经节。

  3. 选择范围

    点击一节可单选。按住 Shift 再点击另一节，可选择两节之间的连续范围。需要全章时点「选整章」。

  4. 用「+1」和「−1」微调结束节

    每点一次「+1」，就把当前选段后面的一节也选中。比如先选约翰福音 3:16，点一次扩到第 17 节，再点一次扩到第 18 节。每点一次「−1」就去掉选段的最后一节。右侧待播预览会立即更新，核对后再上屏。

  5. 合并多段经文一起投影

    一次读经需要用到多段经文时，可以先把选段排成一份清单，再一次投到大屏。选段可以来自不同章节或书卷，大屏会按清单顺序显示，每段都有自己的经文出处。内容超过一屏时，可在操作台滚动继续展示。

    1. 逐段加入。例如先查找并选中「约 3:16–18」，点「加入清单」。再查找并选中「约 3:19–21」，也点一次「加入清单」。每段都会加到清单末尾。
    2. 调整顺序。在右侧「合并投影清单」里，用每段旁的上移或下移箭头调整读经顺序。选错一段时点该段旁的「移除」。
    3. 核对整份清单。右侧若正在预览单段经文，点「预览清单」。如果按钮已显示「返回选段」，表示当前已在预览整份清单。
    4. 投影到大屏。确认右侧预览里的经文和顺序后，点「投影到大屏」。加入、调整和预览都在待播区完成，大屏会在点击投影后切换到这份清单。

  6. 核对上屏内容

    点「查看上屏」核对大屏画面，点「返回待播」继续准备。经文超出一屏时，可用滚轮或上下方向键滚动，上屏画面的滚动位置会同步到大屏。

    要重新投刚才用过的经文，可在左下角「最近投影」点「恢复」，在待播区核对后再上屏。

用 Ctrl + K（Mac 为 ⌘ + K）聚焦搜索框，用 Alt + Enter 上屏。

诗歌与歌谱

  1. 查找诗歌

    在操作台顶部切换到「诗歌」，按首号、歌名或可搜索的歌词查找。结果太多时，点搜索框旁的「筛选」，选择「仅歌名」或「仅当前诗集」。

  2. 选择资料并投影

    选中曲目后，按该首可用的资料选择歌词、简谱或五线谱。确认右侧预览，再点「投影到大屏」。

  3. 放大或缩小歌谱

    打开简谱或五线谱，等右侧谱面加载完成后，点击预览下方的「＋」放大或「−」缩小。两颗按钮之间的百分比表示谱面宽度，可根据大屏的大小和观看距离调整。

    上屏前可以先在预览区调好大小，再点「投影到大屏」。当前预览的谱面已在大屏显示时，调整会立即同步到大屏。

  4. 复制、编辑和恢复歌词

    选中诗歌，在「更多」里点「复制歌词」可复制整首。要改字或补充歌词，点「编辑歌词」。每行写一句，段落之间留一个空行，再点「保存到本机」。已保存过的内置歌词可在编辑窗口点「恢复诗库原文」，再保存生效。

  5. 内置诗集找不到时，添加本地歌谱

    手头有歌谱图片、内置诗集里却找不到这首歌时，点「添加歌谱」。填歌名，选择简谱或五线谱，上传一张 PNG、JPEG 或 WebP 图片。可以顺手补上歌词。保存后，切到「自建诗歌」即可查找和投影。

  6. 用歌谱清单准备多首诗歌

    选好一首诗歌后点「加入清单」。在右侧「歌谱清单」可调整歌序、移除曲目，也可用「上一首」「下一首」切换待播的曲目。核对预览后再上屏。

  7. 用 Excel 批量导入诗歌资料

    在左侧点「下载模板」，按模板填好诗集、首号、歌名和歌词等资料。需要导入歌谱时，在对应列填写图片文件名。点「导入 Excel 诗歌资料」，同时选中一个 .xlsx 文件和表里引用的图片。

  8. 替换歌谱

    打开曲目的简谱或五线谱，在「更多」里点「替换歌谱」。可替换单页或整首、调整页序，也可以恢复原谱。导入和替换的资料保存在当前应用的本机数据中。

多屏投影

  1. 选择多块屏幕

    在「投屏设置」关闭「自动选择一块屏幕」，勾选投影仪或返看屏，再点「保存选择」。可同时选多块屏幕显示同一份内容。

  2. 临时让出大屏，再恢复投影

    要暂时让出大屏给其他窗口，点「最小化投影」或在投影窗口按 Esc。需要继续时，回到操作台点「恢复投影」。

PPT 放映

  1. 导入并放映 PPT 或 PDF

    在顶部切换到「PPT」，点「导入 PPT/PDF 文件」，选择本机的 PPT、PPTX 或 PDF。从文件列表选中演示文稿，在右侧预览并翻到要开始的页面，再点「投影到大屏」。同一份演示已经上屏时，用预览区下方的箭头翻页，大屏会同步。

  2. 检查转换结果和原生放映

    PPT 转换后如果缺字或排版错位，可以在制作原稿的电脑上导出 PDF，再导入投影。如需播放动画、转场或内嵌音视频，在装有 Microsoft PowerPoint 的 Windows 客户端使用「PowerPoint 原生放映」，选择原始文件后点「开始放映」。

音频与视频

  1. 播放音频或伴奏

    在顶部切换到「媒体」，选「音频」并点「导入音频文件」。选中曲目后在右侧点「播放」，可调音量或拖动进度条。多首音频可用列表内的上下箭头排序。伴奏在控制台播放，切回经文或诗歌页面后可以继续准备下一段。

  2. 将视频投到大屏

    选择「视频」，点「导入视频文件」。选中视频并核对预览后，点「投影到大屏」。播放中可暂停、拖动进度条或点「回到开头」。视频上屏时，正在播放的音频会暂停。

常见问题

投影仪没有出现在「投屏设置」里
检查投影仪电源、输入源和连接线。在电脑的显示设置中确认外接屏幕已识别并设为扩展显示，再回到「投屏设置」选择目标屏幕。
投影窗口打开了，大屏还是黑色
首次上屏前是黑屏。请先选一段经文或一首诗歌，确认预览有内容，再点「投影到大屏」。若画面出现在电脑屏上，请检查扩展显示和目标屏幕的选择。
歌谱打不开或需要离线使用
安装版首次读取尚未缓存的在线谱图需要联网。恢复网络后可点「重试歌谱」。有离线需要时，可在聚会前逐首打开要用的谱图并确认预览可读。
重新接好投影仪后画面没有恢复
先到「投屏设置」确认目标屏幕已连接。若显示「未连接」，重新勾选当前屏幕并保存，再点「投影到大屏」。
